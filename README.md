# 🎓 Soutenance de mémoire — Maxime LOUSTALET

**L'intégration de l'intelligence artificielle dans les PME : entre opportunités perçues et freins organisationnels — le cas d'Arla Groupe**
Master 2 · Eklore-ed School of Management · Directeur de recherche : Victor COMBES · 2025–2026

Ce dossier contient tout le nécessaire pour réussir l'oral et viser le haut du barème.

## 📦 Contenu

| Fichier | À quoi ça sert |
|---|---|
| **`Soutenance_MFE_LOUSTALET_Maxime.pptx`** | Le diaporama (21 diapositives), **éditable**. Le script oral est déjà dans les *notes du présentateur* de chaque diapo. |
| **`apercu-diaporama.html`** | Version web du diaporama, à ouvrir dans un navigateur (aperçu ou présentation plein écran, navigation ↑ ↓). |
| **`Script-oral-soutenance.md`** | **Ce que je dois dire**, diapo par diapo, minuté pour 20 min + questions probables du jury. |
| **`Prompt-a-poser-a-Claude.md`** | Le prompt prêt à copier pour (re)générer ou améliorer le diaporama avec Claude. |
| **`build_deck.py`** | Le script Python (python-pptx) qui génère le `.pptx` — pour régénérer après modification. |

## ▶️ Comment l'utiliser

1. Ouvre le **`.pptx`** dans PowerPoint / Keynote / Google Slides.
2. Passe en mode **Présentateur** pour voir le script dans les notes.
3. Répète à voix haute avec le **`Script-oral-soutenance.md`** (chronométré).
4. Révise le tableau des **questions du jury** en fin de script.

## 🎯 Points couverts (barème de soutenance)

1. Contexte & problématique · 2. Cadre théorique + auteurs clés · 3. Méthodologie empirique · 4. Résultats reliés à la littérature · 5. Apports scientifiques + préconisations · 6. Conclusion + limites — **plus** une diapositive dédiée à l'apport professionnel.

## 🔧 Régénérer le PPTX

```bash
pip install python-pptx
python3 build_deck.py
```
